## 🚀 The 9 Featured Engineering Architectures

### 1. 🛰️ GNSS Multi-Stream Precision Positioning Engine
- **Executive Brief**: Software-defined multi-constellation GNSS signal fusion engine benchmarking multi-stream corrections against 2cm RTK ground truth across calibration and 20 KM road drives.
- **Stack**: Python, NumPy, SciPy, Geodesy (ECEF/ENU), Extended Kalman Filtering (EKF), Rauch-Tung-Striebel (RTS), XGBoost, LightGBM.
- **Key Metrics**:
  - `1.235m RMS` Horizontal trajectory error (88.4% error reduction over raw consumer GPS at 10.89m RMS).
  - `0.062 m/s` Kinematic dead-reckoning drift during 60-second complete satellite tunnel blackouts.
  - `2,493 Epochs` Validated against NovAtel ProPak6 2cm NRTK ground truth.

### 2. 🎧 AudioSage: Audiophile Research Assistant & Acoustic Suite
- **Executive Brief**: In-browser Web Audio DSP tuning workbench and real-time Windows Equalizer APO bridge featuring automated parametric EQ generation and verbatim Harman target curve matching.
- **Stack**: React 19, TypeScript, Web Audio API (BiquadFilterNode), Windows Equalizer APO Bridge, Gemini 3.6 Flash, Tailwind CSS, Vite.
- **Key Metrics**:
  - `≤ 0.5 dB RMS` Residual error against Harman In-Ear 2019 target via logarithmic greedy search (48 steps/decade).
  - `23 ms` Live tab audio capture latency with a 30ms anti-pop crossfader.
  - `301 Points` Verbatim implementation of verbatim Harman 2019 and Crinacle IEF acoustic datasets.

### 3. 🎯 The Silent AI Daily Auditor & Life Chronicle

- **Stack**: Python 3.11, Win32 ctypes API, pycaw (Windows CoreAudio), FastAPI, Server-Sent Events (SSE), Google Gemini 3.5 Flash-Lite, Supabase.
- **Key Metrics**:

## 💻 Getting Started Locally

### Prerequisites
- Node.js 18.17+ or 20+
- npm, yarn, or pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/khuzaima175/Porfolio-Project.git
   cd Porfolio-Project
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Launch the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:3000`.

### Production Build

```bash
npm run build
npm run start
```
